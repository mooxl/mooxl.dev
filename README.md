### mooxl.dev

Static [Astro](https://astro.build) site served by Cloudflare Workers static assets.

```
pnpm install
pnpm dev       # local dev server
pnpm preview   # build and serve with the Cloudflare runtime
pnpm deploy    # build and deploy to Cloudflare
```

Fonts are IBM Plex subsets generated by hand from `fonts/` with `uv run scripts/subset-fonts.py`; commit its output. The script header lists when to rerun it.
